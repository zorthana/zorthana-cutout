# Zorthana Cutout

**Open-weight AI for image segmentation and background removal.**

Zorthana Cutout is an AI project focused on separating foreground objects from their backgrounds, making it easier to create clean image cutouts and transparent PNGs.

Designed with accessibility, efficiency, and openness in mind, the project aims to make AI-powered image segmentation available for practical applications, including product photography and image editing.

## Features

- **Background Removal** — Separate foreground objects from image backgrounds.
- **Image Segmentation** — Generate masks identifying foreground objects.
- **Transparent PNG Output** — Preserve extracted objects on transparent backgrounds.
- **Browser-Based Inference** — Work toward processing images directly in the browser.
- **Open Model Weights** — Aim to provide accessible model weights and reproducible inference.

## Development Status

Zorthana Cutout is currently in early development. Model research, baseline evaluation, and experimentation are underway.

Features and capabilities will be documented as they become available. Performance claims and benchmark results will be published after evaluation.

## Vision

Our goal is to develop efficient, accessible, and well-documented AI models for image segmentation, starting with foreground extraction and expanding as the project evolves.
